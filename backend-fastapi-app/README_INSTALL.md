# 后端安装指南

## 概述

`install.sh` 是一个专门用于安装和配置 Zayum Admin 系统后端的自动化脚本。该脚本提供了完整的后端安装流程，包括环境检查、依赖安装、数据库配置、管理员设置等功能。

## 功能特性

- ✅ 系统环境检查
- ✅ Python 依赖自动安装
- ✅ 多数据库支持 (MySQL/PostgreSQL/SQLite)
- ✅ 交互式数据库配置
- ✅ 管理员账户设置
- ✅ 数据库迁移和初始数据恢复
- ✅ 可选的服务启动
- ✅ 详细的安装结果展示

## 使用方法

### 1. 运行安装脚本

```bash
cd backend-fastapi-app
./install.sh
```

### 2. 安装流程

脚本将引导您完成以下步骤：

1. **系统检查**
   - 检查是否已安装
   - 验证 Python 和 pip 环境

2. **依赖安装**
   - 自动安装 requirements.txt 中的所有依赖包

3. **数据库配置**
   - 选择数据库类型 (MySQL/PostgreSQL/SQLite)
   - 配置数据库连接参数
   - 自动生成 .env 配置文件

4. **管理员设置**
   - 设置管理员账户信息
   - 可选择使用默认配置或自定义配置

5. **数据库迁移**
   - 执行 Alembic 数据库迁移
   - 插入初始数据

6. **服务启动** (可选)
   - 可选择是否立即启动后端服务
   - 自动检查服务健康状态

## 数据库支持

### MySQL (默认)
- 默认用户名: `root`
- 默认密码: `password`
- 默认数据库: `zayum_admin`
- 默认主机: `localhost`
- 默认端口: `3306`

### PostgreSQL
- 默认用户名: `postgres`
- 默认密码: `password`
- 默认数据库: `zayum_admin`
- 默认主机: `localhost`
- 默认端口: `5432`

### SQLite
- 数据库文件: `db.sqlite3`
- 无需额外配置

## 安装后操作

### 服务管理

如果选择启动服务，可以使用以下命令管理：

```bash
# 停止服务
kill <PID>

# 手动启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 查看服务状态
curl http://localhost:8000/health
```

### 访问地址

安装完成后，可以通过以下地址访问：

- **API 文档**: http://localhost:8000/docs
- **健康检查**: http://localhost:8000/health
- **后端 API**: http://localhost:8000

## 重新安装

如需重新安装系统，请先删除安装锁定文件：

```bash
rm install.lock
```

然后重新运行安装脚本。

## 故障排除

### 常见问题

1. **依赖安装失败**
   - 检查网络连接
   - 确保 pip 版本最新
   - 检查 requirements.txt 文件是否存在

2. **数据库连接失败**
   - 验证数据库服务是否运行
   - 检查数据库连接参数
   - 确认数据库用户权限

3. **服务启动失败**
   - 检查端口 8000 是否被占用
   - 查看应用日志获取详细错误信息

### 日志文件

- 应用日志: `logs/app.log`
- 安装日志: 控制台输出

## 配置文件

安装过程中会生成以下配置文件：

- `.env`: 环境变量配置文件
- `alembic.ini`: 数据库迁移配置文件
- `install.lock`: 安装锁定文件
- `.backend_pid`: 服务进程ID文件 (如启动服务)

## 安全建议

1. **修改默认密码**
   - 安装完成后立即修改管理员密码
   - 使用强密码策略

2. **数据库安全**
   - 使用非默认端口
   - 限制数据库访问IP
   - 定期备份数据

3. **服务安全**
   - 配置防火墙规则
   - 使用 HTTPS
   - 定期更新依赖包

## 技术支持

如遇到安装问题，请检查：

1. 系统环境是否符合要求
2. 数据库服务是否正常运行
3. 网络连接是否正常
4. 查看详细的错误日志

如需进一步帮助，请参考项目文档或联系技术支持。
